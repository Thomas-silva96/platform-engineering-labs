## 5. Aprendizados

* Qual é a diferença entre Git e GitHub? Git é o sistema de controle de versionamento e o Github e a plataforma de hospedagem e colaboração baseada em git.
* O que acontece durante um commit? Durante um commit as alterações feitas são registradas localmente e assim ficando preparadas para realizar um pull request. 
* Por que usar branches e Pull Requests? Para garantirmos segurança do código, com as branches podemos criar um ambiente separado para trabalhar sem causar interferencia no código principal e o pull request é feito para validação e analise dessas mudanças antes de ser adicionado ao código principal e assim não ter nenhum problema.

## 6. Erros e troubleshooting
