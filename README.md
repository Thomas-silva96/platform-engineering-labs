# Platform Engineering Labs

Repositório de estudos e laboratórios práticos para minha formação em Platform Engineering, Cloud Computing, DevOps e SRE.

## Objetivo

Desenvolver conhecimento técnico por meio de estudos, laboratórios reproduzíveis, troubleshooting e documentação de decisões arquiteturais.

## Trilha de estudos

* [ ] Git e GitHub
* [ ] Linux
* [ ] AWS
* [ ] Terraform
* [ ] DevOps e SRE
* [ ] Docker e Kubernetes
* [ ] CI/CD
* [ ] IA aplicada à engenharia de software
* [ ] Google Cloud

## Metodologia

Cada etapa deve produzir conhecimento, aplicação prática, evidência de funcionamento, registro de erros e troubleshooting.

## Evidências

Os laboratórios e sua documentação serão organizados por tecnologia. Credenciais e badges serão adicionados após a conclusão dos respectivos treinamentos.
